# Structural version merge handoff

The version-merge branches use `studio-hml` and `engine-hml`. Engine integration `e2c92f9` is merged locally as signed `5ee6ffb`; Studio starts from `a69d316b`. The earlier HML feature is already integrated separately.

`hm-wasm/src/merge.rs` exports the existing worker protocol. `merge_core.rs` performs deterministic three-way property merging; `merge_document.rs` builds review groups, manifests, typed models and roundtrip validation; `merge_text.rs` aligns wire units with their formatting, controls and annotation anchors; `merge_resources.rs` compares logical resource values and remaps selected dependencies through the clipboard importer; `merge_container.rs` keeps native source context and handles opaque members. The engine README maps these modules and tests.

The worker uses hm-wasm directly. Manifest version 4 rebuilds older parser views while retaining inherited branch identities. Existing version-store transactions and composite history still apply the merged bytes and ordered branch parents together. Review groups accept current/incoming decisions; accepting an incoming group retains compatible current property edits inside that group. Generic property APIs retain manual and keep-both support. Known fingerprint and review-position aliases from the resolver are accepted; unknown, stale and unresolved decisions fail.

Materialization preserves the current native container, imports referenced definitions and exact binary payloads, and invalidates source spans when their archive context changes. Selected scripts and unknown CFB/ZIP members preserve their bytes. Header extras and manifest metadata retain the selected source context. Native HWPX writing now supports section addition/removal and preserves custom attributes on imported binary manifest entries. Foreign image IDs regenerate their native package bindings rather than reusing a colliding source ID.

`Doc.verifyHwp()` closes the previous verifier schema mismatch. It reopens the actual export and compares typed persistent properties and resource values, excluding source spans, layout caches and regenerated package bindings. Structural materialization also checks this roundtrip before returning bytes. SharedBytes serializes only its viewed span. Paragraph numbering restarts remain session-only and absent from persistent merge views.

Opaque namespace changes, cross-format opaque contexts and opaque records whose numeric resource dependencies cannot be preserved fail explicitly. Missing selected image/object bytes also fail. Large text alignments exceed a bounded budget by becoming an atomic review conflict. These cases never silently discard unknown content or choose an entire document as a merge result.
