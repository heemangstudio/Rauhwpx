OpenRouter

1OpenRouter 계정 만들기와 크레딧 충전

브라우저에서 가입과 결제를 마치고 HamaEditor로 돌아와요.

1단계와 2단계01–02OpenRouter 열고 Sign Up

openrouter.ai에서 오른쪽 위 Sign Up을 눌러 계정을 만들어요.

3단계와 4단계03–04프로필 메뉴에서 Credits 선택

가입이 끝나면 오른쪽 위 프로필을 열고 Credits를 눌러요.

5단계와 6단계05–06Add Credits 누르고 금액 입력

Credits 화면의 Add Credits를 누르고 결제 수단과 금액을 확인해요. Purchase를 누르면 충전이 끝나요.

HamaEditor

2HamaEditor에서 Pi 연결

충전이 끝나면 앱의 에이전트 연결 설정에서 Pi를 OpenRouter 계정에 연결해요.

7단계와 8단계07–08Pi 선택 후 OpenRouter OAuth

오른쪽 설정 패널의 에이전트 연결 목록에서 Pi를 눌러요. 설정 창이 열리면 브라우저로 로그인 · OpenRouter OAuth를 눌러 연결을 승인해요.

3연결 완료

OAuth 승인을 마치고 돌아오면 Pi에서 OpenRouter 모델을 바로 쓸 수 있어요.
