# Nightly icon

"Moonlit pond": the release hippo, unchanged, at the edge of a night pond, with
a crescent moon in the top-right corner, stars, ripples off its feet and the
moon's reflection on the water. Same 32×32 grid as `../hamaeditor-master.png`.

Generated by `python3 scripts/generate-nightly-icon.py`; do not edit the images
by hand. Change the scene in that script's `SCENE` map. The script fails if the
`#` hippo cells drift from the release master.

| File | Replaces in nightly packages |
| --- | --- |
| `icon.icns` | `build/icon.icns` (macOS app) |
| `icon.ico` | `build/icon.ico` (Windows app and installer), `rhwp-studio/public/favicon.ico` |
| `icon-512.png` | `../logo-512.png` (Linux), `rhwp-studio/public/icons/icon-512.png` |
| `icon-{128,192,256}.png` | `rhwp-studio/public/icons/icon-{128,192,256}.png` |
| `hamaeditor-nightly-master.png` | Source for the files above |

`scripts/apply-nightly-icon.mjs` copies them when the package version is a
nightly (`<version>-nightly.<date>.<sha>`). The desktop package action runs it
before building Studio, and `verify:package` rejects a nightly package without
the nightly icon or a release package with it.
