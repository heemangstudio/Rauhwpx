# Boot logo

"Surface": the wordmark scans on, the hippo surfaces through the x-height of
"tor", blinks, climbs out and yawns into the app-icon pose. 2.7 s, then it
holds the last frame.

Generated by `python3 scripts/generate-boot-logo.py`; do not edit the images by
hand. The script fails if the last pose drifts from `hamaeditor-master.png`.

| File | Use |
| --- | --- |
| `hama-boot-{dark,light}.gif` | 88×36 source, transparent, plays once |
| `hama-boot-{dark,light}@4x.gif` | 352×144, for surfaces that cannot scale with `pixelated` |
| `hama-boot-{dark,light}-still.png` / `@4x` | Final frame for `prefers-reduced-motion` |
| `hama-boot-timeline.json` | Canvas size and per-frame timing (`beat` names the phase) |

The wordmark ink matches `--n-text` and the transparent background takes
`--n-canvas`; pick the file for the effective theme.

Display at an integer multiple of 88×36 with `image-rendering: pixelated`.
Fractional sizes, or HiDPI without `pixelated`, blur the pixels. The GIF
restarts whenever its `src` is set again, so set it once when the boot screen
mounts.
